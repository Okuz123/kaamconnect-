# External Credentials Required

| Service | Purpose | Where to get | Required for launch |
|---------|---------|--------------|---------------------|
| Supabase | Database + Auth + Storage | supabase.com | Yes |
| Razorpay | Payments | razorpay.com | Yes (live) |
| Google OAuth | Social login | console.cloud.google.com | Optional |
| Twilio / MSG91 / AWS SNS | Phone OTP SMS | provider site | Yes (for phone login) |
| Resend / SendGrid | Transactional email | provider site | Recommended |
| Mapbox / Google Maps | Geocoding (optional — OpenStreetMap free default) | provider site | Optional |
| Sentry | Error monitoring | sentry.io | Recommended |
